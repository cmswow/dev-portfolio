R-CMS 설치 자동화

키오스크마다 반복하던 프로그램 설치, 서버 시작 설정, 안전보건자료 복사를 하나의 설치 도구에 묶었습니다.

  • C#
  • WinForms
  • PowerShell
설치 도구 소스 비공개
설치 전 상태 확인
설치 항목과 현재 상태를 첫 화면에 표시하고, 무인 진행이나 단계별 확인을 선택할 수 있게 했습니다.
MSDS 증분 복사
PDF가 없거나 원본과 크기가 다를 때만 복사하고, 확인·복사·교체 건수를 표시합니다. 문서 복사만 따로 실행할 수도 있습니다.
설치 파일 다시 빌드
기존 설치 파일에서 빌드 재료를 추출하고 변경된 소스로 다시 패키징하는 PowerShell 스크립트를 마련했습니다.

0.35는 로컬 빌드를 완료했습니다. 신규 키오스크 설치 검증은 대기 중입니다.

Windows · 단독 및 네트워크 연동

R-CMS 센서 운영 도구

키오스크에서 IoT 센서 전송을 자동으로 시작하고, 전송이 끊겼을 때 작업 상태와 연결을 점검할 수 있게 했습니다.

  • PowerShell
  • 작업 스케줄러
  • 시리얼 통신
센서 도구 소스 비공개
로그온 시 자동 시작
단독 키오스크와 네트워크 연동 환경에 맞는 전송 스크립트를 작업 스케줄러로 실행합니다.
네트워크 연결 대기
네트워크 연동 모드는 연결이 준비될 때까지 전송을 기다리고, 실행 중에도 주소 변경을 확인합니다.
전송 상태 진단
실행 중인 프로세스, 중복 실행, 서버 연결, COM 포트와 전송 로그를 점검하는 스크립트를 구성했습니다.
